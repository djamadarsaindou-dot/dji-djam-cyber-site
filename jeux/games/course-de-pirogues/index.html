Course de pirogues

Course de pirogues à balancier dans le lagon de Mayotte. Voici notre version.

Règles

🛶 Pagaie en alternant gauche / droite (← →, ou Q / D, ou les gros boutons tactiles). Un bon rythme régulier = la pirogue file !

↩️ Pour tourner, pagaie plusieurs fois du même côté : ← ← ← vire à gauche, → → → vire à droite.

💪 Attention à l'endurance : taper trop vite fatigue et la pirogue avance moins.

🟠 Passe entre chaque paire de bouées, dans l'ordre. La flèche indique la suivante.

🪸 Évite les patates de corail, les tortues, les bateaux de pêche et les îlots. Les zones de courant te poussent sur le côté.

🌊 Attrape les vagues parfaites dorées pour un coup de turbo !

🏅 Finis sur le podium pour débloquer la course suivante. Échap / P = pause, M = son.
